##Sugar Mayhem!

The use of AI in this project was very limited only used to make an object bounce on another.

This project is with a sprite moving on ground and the goal is to figure out how to escape (Hint you can't unless you break the game) 

This was by Paxton Neyenhouse, Liam Cubillo, and Kristopher Kopsaftis.
